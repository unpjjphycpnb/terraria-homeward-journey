## Overview

Homeward Journey adds a fully scripted narrative mod to Terraria with original biomes, voiced NPC questlines, custom boss cinematics, and a multi-chapter story arc that unfolds across a modded world.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Homeward Journey** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Custom Biomes** | Three new themed biomes with unique terrain, enemies, and drops |
| **Quest System** | NPC-driven multi-step quests with dialogue trees and item rewards |
| **Boss Cinematics** | Scripted intro cutscenes for each major boss encounter |
| **Story Chapters** | Narrative arc divided into three acts unlocked by progression |
